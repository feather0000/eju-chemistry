电极反应规律

電極での反応

$$\ce{Cu^2+ + 2e- -> Cu}$$
$$\ce{2H2O + 2e- -> H2 + 2OH-}$$
$$\ce{2Cl- -> Cl2 + 2e-}$$
$$\ce{2H2O -> O2 + 4H+ + 4e-}$$

阴极（陰極，还原）：Cu²⁺、Ag⁺ 析出金属；离子化倾向大的（Na⁺、K⁺、Al³⁺）不析出，水被还原生成 $\ce{H2}$。阳极（陽極，氧化）：Pt/C 电极上 Cl⁻ → $\ce{Cl2}$；$\ce{SO4^2-}$、$\ce{NO3-}$ 时水被氧化生成 $\ce{O2}$；Cu 等金属阳极本身溶解。

法拉第定律

ファラデーの法則

$$n(e^-)=\frac{It}{9.65\times10^4}$$

工业应用

工業的な応用

铜的电解精炼：粗铜作阳极、纯铜作阴极，比 Cu 不活泼的 Ag、Au 成为阳极泥。离子交换膜法制 NaOH。Al：冰晶石熔融电解 $\ce{Al2O3}$。

$$\ce{Al^3+ + 3e- -> Al}$$

铅蓄电池的质量变化

鉛蓄電池

$$\ce{Pb + SO4^2- -> PbSO4 + 2e-}$$
$$\ce{PbO2 + 4H+ + SO4^2- + 2e- -> PbSO4 + 2H2O}$$

放电时每流过 2 mol 电子：负极增重 $\ce{SO4}=96\,\mathrm g$，正极增重 $\ce{SO2}=64\,\mathrm g$，电解液中 $\ce{H2SO4}$ 减少 2 mol。

例题

例題

例题 1　析出质量

$\ce{CuSO4}$ 水溶液用 2.0 A 电解 965 s，阴极析出 Cu？

解答

$e^-=1930/96500=0.020$ mol，Cu 0.010 mol = 0.635 g。

5.0 A 电流通电 1930 s，流过的电子是？

  1. ① 0.050 mol
  2. ② 0.10 mol
  3. ③ 0.20 mol
  4. ④ 1.0 mol
解答

正解：②

$9650/96500$。

问 2原创 · EJU 风格

$\ce{AgNO3}$ 水溶液用 1.0 A 电解 965 s，阴极析出 Ag 的质量是？

  1. ① 0.54 g
  2. ② 1.08 g
  3. ③ 2.16 g
  4. ④ 10.8 g
解答

正解：②

0.010 mol × 108。

问 3原创 · EJU 风格

用 Pt 电极电解 NaCl 水溶液，阴极生成的物质是？

  1. ① Na
  2. ② $\ce{Cl2}$
  3. ③ $\ce{H2}$
  4. ④ $\ce{O2}$
解答

正解：③

Na⁺ 不被还原，水被还原。

问 4原创 · EJU 风格

用 Pt 电极电解稀硫酸，流过 0.40 mol 电子时阳极生成 $\ce{O2}$ 在标准状况下的体积是？

  1. ① 1.12 L
  2. ② 2.24 L
  3. ③ 4.48 L
  4. ④ 8.96 L
解答

正解：②

$\ce{O2}$ = $e^-$/4 = 0.10 mol。

问 5原创 · EJU 风格

铜的电解精炼中，粗铜中的 Ag 会？

  1. ① 在阴极析出
  2. ② 成为阳极泥
  3. ③ 以 Ag⁺ 留在溶液中
  4. ④ 以气体放出
解答

正解：②

Ag 比 Cu 难氧化，沉到阳极下方。

问 6原创 · EJU 风格

制取 Al 2.7 kg 需要的电量是？

  1. ① $9.65\times10^6$ C
  2. ② $2.9\times10^7$ C
  3. ③ $9.65\times10^7$ C
  4. ④ $2.9\times10^8$ C
解答

正解：②

Al 100 mol × 3 × 96500 ≈ $2.9\times10^7$。

问 7原创 · EJU 风格

用 Cu 电极电解 $\ce{CuSO4}$ 水溶液，阳极的反应是？

  1. ① $\ce{Cu -> Cu^2+ + 2e-}$
  2. ② $\ce{2H2O -> O2 + 4H+ + 4e-}$
  3. ③ $\ce{Cu^2+ + 2e- -> Cu}$
  4. ④ $\ce{2H2O + 2e- -> H2 + 2OH-}$
解答

正解：①

金属阳极本身溶解。

问 8原创 · EJU 风格

用 Pt 电极电解 $\ce{CuSO4}$ 水溶液，阴极析出 Cu 0.635 g 时阳极生成 $\ce{O2}$ 在标准状况下多少 mL？

  1. ① 56 mL
  2. ② 112 mL
  3. ③ 224 mL
  4. ④ 448 mL
解答

正解：②

Cu 0.010 mol → $e^-$ 0.020 → $\ce{O2}$ 0.0050 mol = 112 mL。

问 9原创 · 过去问高频题型

铅蓄电池放电时流过 0.20 mol 电子，负极质量增加多少？

  1. ① $6.4\,\mathrm g$
  2. ② $9.6\,\mathrm g$
  3. ③ $19.2\,\mathrm g$
  4. ④ $20.7\,\mathrm g$
解答

正解：②

0.10 mol $\ce{Pb}\to\ce{PbSO4}$，增重 $0.10\times96=9.6\,\mathrm g$。

问 10原创 · 过去问高频题型

上题中正极质量增加多少？

  1. ① $6.4\,\mathrm g$
  2. ② $9.6\,\mathrm g$
  3. ③ $3.2\,\mathrm g$
  4. ④ $12.8\,\mathrm g$
解答

正解：①

$\ce{PbO2}\to\ce{PbSO4}$，每 mol 增重 64，$0.10\times64=6.4\,\mathrm g$。

问 11原创 · 过去问高频题型

用 $2.0\,\mathrm A$ 电流电解 $\ce{CuSO4}$ 水溶液 $965\,\mathrm s$，阴极析出 Cu 的质量约为？（Cu 63.5，$F=9.65\times10^4$）

  1. ① $0.32\,\mathrm g$
  2. ② $0.64\,\mathrm g$
  3. ③ $1.3\,\mathrm g$
  4. ④ $0.16\,\mathrm g$
解答

正解：②

电子 0.020 mol → Cu 0.010 mol → 0.635 g。

问 12原创 · 过去问高频题型

电解食盐水（离子交换膜法）时，阴极生成的物质是？

  1. ① $\ce{Cl2}$
  2. ② $\ce{O2}$
  3. ③ $\ce{H2}$ 与 $\ce{NaOH}$
