卤素

ハロゲン

$$\ce{MnO2 + 4HCl -> MnCl2 + Cl2 + 2H2O}$$
$$\ce{Cl2 + 2KI -> 2KCl + I2}$$
$$\ce{CaF2 + H2SO4 -> CaSO4 + 2HF}$$

氧化力 $\ce{F2>Cl2>Br2>I2}$。HF 是弱酸，能腐蚀玻璃。

氮・硫

窒素・硫黄

$$\ce{2NH4Cl + Ca(OH)2 -> CaCl2 + 2H2O + 2NH3}$$
$$\ce{2NO + O2 -> 2NO2}$$
$$\ce{3NO2 + H2O -> 2HNO3 + NO}$$
$$\ce{2SO2 + O2 -> 2SO3}$$
$$\ce{Cu + 2H2SO4 -> CuSO4 + 2H2O + SO2}$$

哈伯法（ハーバー・ボッシュ法）制氨；奥斯特瓦尔德法（オストワルト法）制硝酸；接触法制硫酸。浓硫酸：吸水性、脱水性、热浓时氧化性。

金属

金属元素

$$\ce{2Na + 2H2O -> 2NaOH + H2}$$
$$\ce{2Al + 2NaOH + 6H2O -> 2Na[Al(OH)4] + 3H2}$$
$$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$$
$$\ce{NaCl + NH3 + CO2 + H2O -> NaHCO3 + NH4Cl}$$
$$\ce{2NaHCO3 -> Na2CO3 + H2O + CO2}$$

Al、Zn、Sn、Pb 是两性金属。索尔维法（アンモニアソーダ法）制 $\ce{Na2CO3}$。

気体の発生と捕集

过渡金属与配合物

錯イオン

$\ce{Cu^2+}$ 加少量氨水得蓝白色 $\ce{Cu(OH)2}$，过量则溶解成深蓝色 $\ce{[Cu(NH3)4]^2+}$。$\ce{Ag+}$ 过量氨水成 $\ce{[Ag(NH3)2]+}$；$\ce{Zn^2+}$、$\ce{Al^3+}$ 在过量 NaOH 中溶解（$\ce{Zn}$ 也溶于过量氨水）。$\ce{Fe^3+}$ 与 $\ce{SCN-}$ 显血红色。

例题

例題

例题 1　氨的产量

$\ce{N2}$ 2.8 t 全部转化为 $\ce{NH3}$ 可得多少？

解答

$\ce{N2}$ $1.0\times10^5$ mol → $\ce{NH3}$ $2.0\times10^5$ mol = 3.4 t。

问 11原创 · 过去问高频题型

上题滤液中再在酸性条件下通 $\ce{H2S}$，沉淀的是？

  1. ① $\ce{FeS}$
  2. ② $\ce{CuS}$
  3. ③ $\ce{Fe(OH)3}$

正解：②

酸性下只沉淀溶解度很小的 $\ce{CuS}$（黑色）。

问 12原创 · 过去问高频题型

干燥氨气时不能使用的干燥剂是？

  1. ① 碱石灰
  2. ② 生石灰
  3. ③ 浓硫酸
  4. ④ 氢氧化钠固体
解答

正解：③

浓硫酸是酸，会与碱性的 $\ce{NH3}$ 反应。

问 13原创 · 过去问高频题型

向 $\ce{CuSO4}$ 水溶液加过量氨水，溶液呈？

  1. ① 无色
  2. ② 血红色
  3. ③ 深蓝色
  4. ④ 黄色
解答

正解：③

问 14原创 · 过去问高频题型

  1. ① $\ce{Al(OH)3}$
