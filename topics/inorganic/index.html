13 无机物质

非金属（卤素・O・S・N・P・C・Si）与金属（碱金属・碱土金属・Al・Zn・Fe・Cu・Ag）的性质、制法、工业流程与离子检验。

卤素

ハロゲン

$$\ce{MnO2 + 4HCl -> MnCl2 + Cl2 + 2H2O}$$
$$\ce{Cl2 + 2KI -> 2KCl + I2}$$
$$\ce{CaF2 + H2SO4 -> CaSO4 + 2HF}$$

氧化力 $\ce{F2>Cl2>Br2>I2}$。HF 是弱酸，能腐蚀玻璃。

氮・硫

窒素・硫黄

$$\ce{2NH4Cl + Ca(OH)2 -> CaCl2 + 2H2O + 2NH3}$$
$$\ce{2NO + O2 -> 2NO2}$$
$$\ce{3NO2 + H2O -> 2HNO3 + NO}$$
$$\ce{2SO2 + O2 -> 2SO3}$$
$$\ce{Cu + 2H2SO4 -> CuSO4 + 2H2O + SO2}$$

哈伯法（ハーバー・ボッシュ法）制氨；奥斯特瓦尔德法（オストワルト法）制硝酸；接触法制硫酸。浓硫酸：吸水性、脱水性、热浓时氧化性。

金属

金属元素

$$\ce{2Na + 2H2O -> 2NaOH + H2}$$
$$\ce{2Al + 2NaOH + 6H2O -> 2Na[Al(OH)4] + 3H2}$$
$$\ce{Fe2O3 + 3CO -> 2Fe + 3CO2}$$
$$\ce{NaCl + NH3 + CO2 + H2O -> NaHCO3 + NH4Cl}$$
$$\ce{2NaHCO3 -> Na2CO3 + H2O + CO2}$$

Al、Zn、Sn、Pb 是两性金属。索尔维法（アンモニアソーダ法）制 $\ce{Na2CO3}$。

例题

例題

例题 1　氨的产量

$\ce{N2}$ 2.8 t 全部转化为 $\ce{NH3}$ 可得多少？

解答

$\ce{N2}$ $1.0\times10^5$ mol → $\ce{NH3}$ $2.0\times10^5$ mol = 3.4 t。

问 1原创 · EJU 风格

实验室用二氧化锰和浓盐酸制得 $\ce{Cl2}$ 0.10 mol，消耗的 $\ce{MnO2}$ 是（Mn = 55）？

  1. ① 4.35 g
  2. ② 8.7 g
  3. ③ 17.4 g
  4. ④ 34.8 g
解答

正解：②

1:1 → 0.10 × 87。

问 2原创 · EJU 风格

氨用奥斯特瓦尔德法全部转化为硝酸，$\ce{NH3}$ 1.7 kg 可得 $\ce{HNO3}$ 多少？

  1. ① 3.15 kg
  2. ② 6.3 kg
  3. ③ 9.45 kg
  4. ④ 12.6 kg
解答

正解：②

N 守恒：$\ce{NH3}$ 100 mol → $\ce{HNO3}$ 100 mol = 6.3 kg。

问 3原创 · EJU 风格

既能与盐酸反应、又能与 NaOH 水溶液反应生成 $\ce{H2}$ 的金属是？

  1. ① Fe
  2. ② Cu
  3. ③ Al
  4. ④ Mg
解答

正解：③

两性金属。

问 5原创 · EJU 风格

浓硫酸使蔗糖变黑，利用的是浓硫酸的？

问 6原创 · EJU 风格

能腐蚀玻璃的是？

  1. ① HCl
  2. ② HF
  3. ③ $\ce{HNO3}$

解答

正解：②

$\ce{SiO2 + 6HF -> H2SiF6 + 2H2O}$。

问 7原创 · EJU 风格

$\ce{NaHCO3}$ 8.4 g 完全热分解生成 $\ce{CO2}$ 在标准状况下的体积是？

  1. ① 0.56 L
  2. ② 1.12 L
  3. ③ 2.24 L
  4. ④ 4.48 L
解答

正解：②

0.10 mol $\ce{NaHCO3}$ → 0.050 mol $\ce{CO2}$。

问 8原创 · EJU 风格

赤铁矿 $\ce{Fe2O3}$ 1.6 t 用 CO 完全还原可得 Fe？

  1. ① 0.56 t
  2. ② 1.12 t
  3. ③ 1.6 t
  4. ④ 2.24 t
解答

正解：②

$1.6\times112/160=1.12$。
