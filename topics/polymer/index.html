聚合反应

重合反応

加成聚合（付加重合）：乙烯 → 聚乙烯、氯乙烯 → PVC、苯乙烯 → 聚苯乙烯。缩合聚合（縮合重合）：己二酸＋己二胺 → 尼龙 66（酰胺键）；对苯二甲酸＋乙二醇 → PET（酯键）。

$$\text{聚合度 }n=\frac{\text{高分子分子量}}{\text{重复单元式量}}$$

糖类

糖類

$$\ce{C6H12O6 -> 2C2H5OH + 2CO2}$$
$$\ce{C12H22O11 + H2O -> 2C6H12O6}$$

单糖：葡萄糖、果糖（有还原性）；二糖：麦芽糖（还原性）、蔗糖（无还原性）；多糖：淀粉（碘-淀粉反应显蓝紫）、纤维素。

氨基酸与蛋白质

アミノ酸・タンパク質

α-氨基酸通过肽键（ペプチド結合 –CO–NH–）连接。检验：双缩脲反应（ビウレット反応，紫色，含两个以上肽键）、黄蛋白反应（キサントプロテイン反応，苯环）、茚三酮反应（ニンヒドリン反応）。加热・重金属离子使其变性。

油脂

油脂

$$\ce{C3H5(OCOR)3 + 3NaOH -> C3H5(OH)3 + 3RCOONa}$$

皂化值：1 mol 油脂需 3 mol KOH；碘值反映不饱和度（C=C 数）。

例题

例題

例题 1　聚合度

分子量 $2.8\times10^4$ 的聚乙烯聚合度？

解答

重复单元 $\ce{C2H4}$ = 28，$n=1000$。

问 5原创 · EJU 风格

  2. ② 207

问 8原创 · EJU 风格

  2. ② 90 g
  3. ③ 99 g

问 9原创 · 过去问高频题型

下列高分子中由缩聚反应合成的是？

  1. ① 聚乙烯
  2. ② 聚氯乙烯
  3. ③ 尼龙 66
  4. ④ 聚苯乙烯
解答

正解：③

问 10原创 · 过去问高频题型

  4. ④ 280

问 11原创 · 过去问高频题型

问 12原创 · 过去问高频题型

只由 α-葡萄糖构成的多糖是？

  1. ① 纤维素
  2. ② 淀粉
  3. ③ 蔗糖
  4. ④ 核糖
解答
