物质的分类

純物質と混合物

纯净物（純物質）有固定的组成、熔点和沸点；混合物（混合物）如空气、海水、石油，熔沸点不固定。纯净物又分为只由一种元素构成的单质（単体）与由两种以上元素构成的化合物（化合物）。

注意　“元素”是成分的名称（如“骨中含钙”），“单质”是实际的物质（如“金属钙与水反应”）。EJU 常考这两种说法的区分。

同素异形体

同素体

由同一元素构成、性质不同的单质互为同素异形体。记忆口诀 SCOP：S（斜方硫・单斜硫・橡胶状硫）、C（金刚石・石墨・富勒烯）、O（$\ce{O2}$・$\ce{O3}$）、P（白磷・红磷）。

易错　$\ce{^{12}C}$ 与 $\ce{^{13}C}$ 是同位素（同位体），不是同素异形体。

分离与提纯

分離・精製

方法日本語原理・例
过滤ろ過固体与液体分离（泥水）
蒸馏蒸留利用沸点差（海水→淡水）
分馏分留多种液体按沸点分开（石油、液态空气）

元素的检出

成分元素の検出

焰色反应（炎色反応）：Li 红、Na 黄、K 红紫、Ca 橙红、Sr 深红、Ba 黄绿、Cu 蓝绿。$\ce{Cl}$ 用 $\ce{AgNO3}$ 生成白色沉淀检出；C 燃烧生成 $\ce{CO2}$ 使石灰水变浑浊。

$$\ce{Ag+ + Cl- -> AgCl v}$$
$$\ce{Ca(OH)2 + CO2 -> CaCO3 v + H2O}$$

定量实验器具

定量実験の器具

器具用途水洗后
全量吸管（ホールピペット）准确量取用待取溶液润洗（共洗い）
滴定管（ビュレット）滴下体积用待装溶液润洗
容量瓶（メスフラスコ）配制定容湿着可用
锥形瓶（コニカルビーカー）反应容器湿着可用

理由　容量瓶和锥形瓶里“溶质的物质的量”才是关键，多余的水不影响；吸管和滴定管若有水会把溶液稀释。

例题

例題

例题 1　分离方法的选择

要从含少量氯化钠的硝酸钾中得到纯的硝酸钾，最合适的方法是？

解答

$\ce{KNO3}$ 溶解度随温度变化大，而 NaCl 几乎不变：高温饱和溶解后冷却，只有 $\ce{KNO3}$ 析出——重结晶。

例题 2　单质还是元素

“水由氢和氧组成”中的“氢”指的是？

解答

指成分 → 元素。而“氢气燃烧”中的氢是单质。

練習問題（11 题，选择题；原子量 H 1.0, C 12, N 14, O 16, Na 23, Mg 24, Al 27, S 32, Cl 35.5, K 39, Ca 40, Fe 56, Cu 63.5, Ag 108，另有说明除外）

问 1原创 · EJU 风格

下列物质中属于混合物的是？

  1. ① 干冰
  2. ② 氨
  3. ③ 石油
  4. ④ 氯化钠
解答

正解：③

石油是多种烃的混合物；其余都是纯净物。

问 2原创 · EJU 风格

下列各组中，互为同素异形体的是？

  1. ① $\ce{^{35}Cl}$ 与 $\ce{^{37}Cl}$
  2. ② 金刚石与石墨
  3. ③ 水与过氧化氢
  4. ④ 一氧化碳与二氧化碳
解答

正解：②

同一元素 C 的不同单质。① 是同位素，③④ 是不同化合物。

问 3原创 · EJU 风格

从石油中分出汽油、煤油、轻油等成分的方法是？

  1. ① 过滤
  2. ② 升华
  3. ③ 分馏
  4. ④ 萃取
解答

正解：③

按沸点区间分离多种液体 → 分馏。

问 4原创 · EJU 风格

含少量砂子的碘，提纯碘最适合的方法是？

  1. ① 升华法
  2. ② 过滤
  3. ③ 蒸馏
  4. ④ 色谱法
解答

正解：①

碘易升华，加热后在冷的表面凝华收集。

问 5原创 · EJU 风格

某溶液的焰色反应呈黄色，溶液中一定含有的元素是？

  1. ① K
  2. ② Ca
  3. ③ Na
  4. ④ Cu
解答

正解：③

Na 呈黄色。

问 6原创 · EJU 风格

下列说法中“氧”指单质的是？

  1. ① 水中含有氧
  2. ② 臭氧和氧气都由氧构成
  3. ③ 植物的光合作用放出氧
  4. ④ 二氧化硅中含有氧
解答

正解：③

放出的是 $\ce{O2}$ 这一物质 → 单质。其余都指元素。

问 7原创 · EJU 风格

下列关于纯净物的说法正确的是？

  1. ① 空气在一定压强下有固定沸点
  2. ② 纯净物在一定压强下熔点固定
  3. ③ 海水是化合物
  4. ④ 单质由两种以上元素构成
解答

正解：②

纯净物熔沸点固定；空气、海水是混合物。

问 8原创 · EJU 风格

向某无色溶液中加入硝酸银溶液生成白色沉淀，该溶液可能含有？

  1. ① $\ce{Cl-}$
  2. ② $\ce{NO3-}$
  3. ③ $\ce{Na+}$
  4. ④ $\ce{K+}$
解答

正解：①

$\ce{Ag+ + Cl- -> AgCl}$（白色）。

问 9原创 · 过去问高频题型

中和滴定中，用蒸馏水洗净后必须用待装溶液润洗再使用的器具组合是？

  1. ① 全量吸管、容量瓶
  2. ② 全量吸管、滴定管
  3. ③ 容量瓶、锥形瓶
  4. ④ 锥形瓶、滴定管
解答

正解：②

量取/滴下溶液的器具内残留水会稀释溶液。

问 10原创 · 过去问高频题型

用分液漏斗把碘从碘水中转移到有机溶剂中的操作叫？

  1. ① 蒸馏
  2. ② 萃取
  3. ③ 升华
  4. ④ 重结晶
解答

正解：②

利用溶解度差把溶质转入另一种不相溶溶剂 → 萃取。

问 11原创 · 过去问高频题型

浓度未知的食醋 $10.0\,\mathrm{mL}$ 稀释到 $100\,\mathrm{mL}$，取 $10.0\,\mathrm{mL}$ 用 $0.100\,\mathrm{mol/L}$ NaOH 滴定需 $7.50\,\mathrm{mL}$。原食醋中乙酸的浓度是？

  1. ① $0.0750\,\mathrm{mol/L}$
  2. ② $0.750\,\mathrm{mol/L}$
  3. ③ $7.50\,\mathrm{mol/L}$
  4. ④ $0.375\,\mathrm{mol/L}$
解答

正解：②

稀释液 $0.100\times7.50/10.0=0.0750$，原液 10 倍：$0.750\,\mathrm{mol/L}$。
