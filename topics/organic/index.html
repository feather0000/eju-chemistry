元素分析

元素分析

$$\ce{C}=\ce{CO2}\times\frac{12}{44},\ \ce{H}=\ce{H2O}\times\frac{2}{18}$$

由质量求最简式（組成式），再由分子量求分子式。

烃

炭化水素

$$\ce{CH4 + Cl2 -> CH3Cl + HCl}$$
$$\ce{C2H4 + Br2 -> C2H4Br2}$$
$$\ce{C2H4 + H2O -> C2H5OH}$$
$$\ce{CaC2 + 2H2O -> Ca(OH)2 + C2H2}$$

烷烃 $\ce{C_nH_{2n+2}}$ 取代反应；烯烃 $\ce{C_nH_{2n}}$、炔烃加成反应（溴水褪色）。

含氧化合物

酸素を含む化合物

$$\ce{2C2H5OH + 2Na -> 2C2H5ONa + H2}$$
$$\ce{CH3COOH + C2H5OH <=> CH3COOC2H5 + H2O}$$

伯醇 → 醛 → 羧酸；仲醇 → 酮。醛有还原性：银镜反应、斐林反应。碘仿反应：$\ce{CH3CO-}$ 或 $\ce{CH3CH(OH)-}$。

芳香族化合物

芳香族化合物

$$\ce{C6H6 + HNO3 -> C6H5NO2 + H2O}$$
$$\ce{C6H5OH + NaOH -> C6H5ONa + H2O}$$

苯主要发生取代反应。苯酚：弱酸性，$\ce{FeCl3}$ 显紫色。苯胺：碱性，漂白粉溶液显紫色。酸性强弱：盐酸・磺酸 > 羧酸 > 碳酸 > 苯酚。

碘仿反应与芳香族的萃取分离

ヨードホルム反応・抽出分離

碘仿反应（$\ce{I2}$ + NaOH，黄色 $\ce{CHI3}$）阳性：含 $\ce{CH3CO-}$ 或 $\ce{CH3CH(OH)-}$ 的化合物，如乙醇、乙醛、丙酮、2-丙醇。

萃取分离（乙醚层 / 水层）：加 NaOH 水溶液 → 苯酚、苯甲酸成钠盐进入水层；再通 $\ce{CO2}$ → 只有苯酚游离（碳酸比苯酚强、比羧酸弱）；加盐酸 → 苯胺成盐进入水层；中性的甲苯、硝基苯留在乙醚层。

异构体与不对称碳

異性体・不斉炭素

$\ce{C4H10}$ 2 种，$\ce{C5H12}$ 3 种；$\ce{C4H10O}$ 醇 4 种（其中 2-丁醇含不对称碳）；$\ce{C4H8}$ 烯烃含顺反异构共 4 种。连有 4 个不同原子/基团的碳是不对称碳。

例题

例題

例题 1　分子式

某有机物（C,H,O）23 mg 燃烧得 $\ce{CO2}$ 44 mg、$\ce{H2O}$ 27 mg，分子量 46。

解答

C 12 mg、H 3 mg、O 8 mg → C:H:O = 1:3:0.5 = 2:6:1 → $\ce{C2H6O}$。

问 13原创 · 过去问高频题型
