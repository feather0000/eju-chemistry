氧化数

酸化数

失去电子＝氧化（氧化数增大），得到电子＝还原（氧化数减小）。规则：单质 0；化合物中 H 为 +1、O 为 −2（$\ce{H2O2}$ 中 −1）；总和 = 电荷。

氧化剂与还原剂

酸化剤・還元剤

$$\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$$
$$\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}$$
$$\ce{H2O2 + 2H+ + 2e- -> 2H2O}$$
$$\ce{(COOH)2 -> 2CO2 + 2H+ + 2e-}$$
$$\ce{Fe^2+ -> Fe^3+ + e-}$$

电子数相等地组合两半反应 → 离子方程式。

$$\ce{2MnO4- + 6H+ + 5H2O2 -> 2Mn^2+ + 8H2O + 5O2}$$

离子化倾向

イオン化傾向

Li > K > Ca > Na > Mg > Al > Zn > Fe > Ni > Sn > Pb > (H₂) > Cu > Hg > Ag > Pt > Au

$$\ce{Zn + Cu^2+ -> Zn^2+ + Cu}$$
$$\ce{Cu + 2Ag+ -> Cu^2+ + 2Ag}$$

电池

電池

$$\ce{Pb + PbO2 + 2H2SO4 -> 2PbSO4 + 2H2O}$$
$$\ce{2H2 + O2 -> 2H2O}$$

负极（負極）发生氧化，正极（正極）发生还原。丹尼尔电池：Zn | $\ce{ZnSO4}$ ‖ $\ce{CuSO4}$ | Cu。铅蓄电池放电时两极都生成 $\ce{PbSO4}$，质量增加。

氧化还原滴定

酸化還元滴定

$$\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}$$
$$\ce{H2O2 -> O2 + 2H+ + 2e-}$$
$$\ce{(COOH)2 -> 2CO2 + 2H+ + 2e-}$$

终点：$\ce{MnO4-}$ 的紫红色不再消失。计量关系用“氧化剂得电子 mol = 还原剂失电子 mol”。

例题

例題

例题 1　氧化还原滴定

0.050 mol/L $\ce{(COOH)2}$ 10 mL 用 $\ce{KMnO4}$ 滴定消耗 8.0 mL，$\ce{KMnO4}$ 浓度？

解答

电子：$0.050\times10\times2=c\times8.0\times5$，$c=0.025$ mol/L。

问 1原创 · EJU 风格

$\ce{K2Cr2O7}$ 中 Cr 的氧化数是？

  1. ① +3
  2. ② +4
  3. ③ +6
  4. ④ +7
解答

正解：③

$2+2x-14=0$。

问 2原创 · EJU 风格

$\ce{MnO4-}$ 中 Mn 的氧化数是？

  1. ① +2
  2. ② +4
  3. ③ +6
  4. ④ +7
解答

正解：④

$x-8=-1$。

问 3原创 · EJU 风格

下列反应中 $\ce{H2O2}$ 作还原剂的是？

  1. ① 与 KI 反应
  2. ② 与 $\ce{KMnO4}$（酸性）反应
  3. ③ 与 $\ce{Fe^2+}$ 反应
  4. ④ 与 $\ce{H2S}$ 反应
解答

正解：②

遇强氧化剂 $\ce{KMnO4}$ 时放出 $\ce{O2}$。

问 4原创 · EJU 风格

0.10 mol/L $\ce{FeSO4}$ 20 mL 被酸性 0.020 mol/L $\ce{KMnO4}$ 完全氧化，需要多少 mL？

  1. ① 4.0
  2. ② 10
  3. ③ 20
  4. ④ 50
解答

正解：③

$0.1\times20\times1=0.02V\times5$，$V=20$。

问 5原创 · EJU 风格

将铁片放入下列溶液中，铁片表面析出金属的是？

  1. ① $\ce{ZnSO4}$
  2. ② $\ce{MgCl2}$
  3. ③ $\ce{CuSO4}$
  4. ④ $\ce{Al2(SO4)3}$
解答

正解：③

Fe 比 Cu 离子化倾向大。

问 6原创 · EJU 风格

丹尼尔电池中发生氧化反应的电极是？

  1. ① Zn 负极
  2. ② Zn 正极
  3. ③ Cu 负极
  4. ④ Cu 正极
解答

正解：①

$\ce{Zn -> Zn^2+ + 2e-}$。

问 7原创 · EJU 风格

铅蓄电池放电时流过 0.20 mol 电子，负极质量增加多少？

  1. ① 4.8 g
  2. ② 9.6 g
  3. ③ 19 g
  4. ④ 30 g
解答

正解：②

$\ce{Pb + SO4^2- -> PbSO4 + 2e-}$，0.10 mol × 96（$\ce{SO4}$）= 9.6 g。

问 8原创 · EJU 风格

不与稀盐酸反应的金属是？

  1. ① Zn
  2. ② Fe
  3. ③ Mg
  4. ④ Cu

正解：④

Cu 在 $\ce{H2}$ 之后。

问 9原创 · 过去问高频题型

$0.020\,\mathrm{mol/L}$ $\ce{KMnO4}$（硫酸酸性）滴定 $\ce{H2O2}$ 水溶液 $10.0\,\mathrm{mL}$ 用去 $16.0\,\mathrm{mL}$。$\ce{H2O2}$ 浓度是？

  1. ① $0.032\,\mathrm{mol/L}$
  2. ② $0.064\,\mathrm{mol/L}$
  3. ③ $0.080\,\mathrm{mol/L}$
  4. ④ $0.16\,\mathrm{mol/L}$
解答

正解：③

$5\times0.020\times16.0=2\times c\times10.0$，$c=0.080\,\mathrm{mol/L}$。

问 10原创 · 过去问高频题型

$\ce{K2Cr2O7}$ 中 Cr 的氧化数是？

  1. ① +3
  2. ② +6
  3. ③ +7
  4. ④ +12
解答

正解：②

$2\cdot1+2x-14=0$，$x=+6$。

问 11原创 · 过去问高频题型

在 $\ce{SO2 + 2H2S -> 3S + 2H2O}$ 中，$\ce{SO2}$ 的作用是？

  1. ① 还原剂
  2. ② 氧化剂
  3. ③ 催化剂
  4. ④ 既非氧化剂也非还原剂
解答

正解：②

S 由 +4 变为 0，被还原，故 $\ce{SO2}$ 是氧化剂。

问 12原创 · 过去问高频题型

  3. ③ $\ce{NO2}$
  4. ④ $\ce{HNO3}$
解答

正解：④

−3、+2、+4、+5。
