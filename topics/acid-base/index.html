酸碱的定义

酸・塩基の定義

$$\ce{HCl -> H+ + Cl-}$$
$$\ce{NH3 + H2O <=> NH4+ + OH-}$$

阿伦尼乌斯：水中给出 $\ce{H+}$ / $\ce{OH-}$。布朗斯特：给出 $\ce{H+}$ 的是酸，接受的是碱。强酸：HCl、$\ce{HNO3}$、$\ce{H2SO4}$；强碱：NaOH、KOH、$\ce{Ca(OH)2}$、$\ce{Ba(OH)2}$。

pH

水素イオン濃度

$$K_w=[\ce{H+}][\ce{OH-}]=1.0\times10^{-14}\ (25\,{}^\circ\mathrm C)$$
$$[\ce{H+}]=c\alpha\cdot(\text{价数})$$

中和与滴定

中和滴定

$$\ce{H2SO4 + 2NaOH -> Na2SO4 + 2H2O}$$
$$\ce{CH3COOH + NaOH -> CH3COONa + H2O}$$
$$a\,c\,V=b\,c'\,V'$$

指示剂：强酸×强碱 两者皆可；弱酸×强碱 用酚酞（碱性侧变色）；强酸×弱碱 用甲基橙。

盐的水解・缓冲

塩の加水分解・緩衝液

$$\ce{CH3COO- + H2O <=> CH3COOH + OH-}$$

弱酸＋强碱的盐显碱性，强酸＋弱碱的盐显酸性。醋酸与醋酸钠的混合液为缓冲溶液。

滴定曲线与指示剂

滴定曲線と指示薬

组合中和点指示剂
强酸 × 强碱pH≈7酚酞・甲基橙都可
弱酸 × 强碱（醋酸+NaOH）碱性酚酞
强酸 × 弱碱（HCl+氨水）酸性甲基橙

问 9原创 · 过去问高频题型

$0.20\,\mathrm{mol/L}$ 盐酸 $10\,\mathrm{mL}$ 与 $0.10\,\mathrm{mol/L}$ NaOH $10\,\mathrm{mL}$ 混合（$\log2=0.30$），pH 约为？

  1. ① 0.70
  2. ② 1.0
  3. ③ 1.3
  4. ④ 2.0
解答

正解：③

剩余 $\ce{H+}$ $1.0\times10^{-3}$ mol / 20 mL $=5.0\times10^{-2}\,\mathrm{mol/L}$，pH $=2-\log5=1.3$。

问 10原创 · 过去问高频题型

用 NaOH 标准液滴定醋酸时最适合的指示剂是？

  1. ① 甲基橙
  2. ② 酚酞
  3. ③ 两者都不行
  4. ④ 淀粉
解答

正解：②

中和点偏碱性，用酚酞（变色 pH 8–10）。

问 11原创 · 过去问高频题型

$\ce{H2SO4}$ 水溶液 $10\,\mathrm{mL}$ 恰好被 $0.20\,\mathrm{mol/L}$ NaOH $15\,\mathrm{mL}$ 中和。硫酸浓度是？

  1. ① $0.075\,\mathrm{mol/L}$
  2. ② $0.15\,\mathrm{mol/L}$
  3. ③ $0.30\,\mathrm{mol/L}$
  4. ④ $0.60\,\mathrm{mol/L}$
解答

正解：②

$2c\times10=0.20\times15$，$c=0.15\,\mathrm{mol/L}$。

问 12原创 · 过去问高频题型
