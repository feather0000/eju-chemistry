物质的量

物質量

$$N_A=6.0\times10^{23}\,/\mathrm{mol}$$
$$n=\frac{m}{M}$$
$$V=22.4n\ \mathrm{L}\ (0\,{}^\circ\mathrm C,\ 1.013\times10^5\,\mathrm{Pa})$$

化学方程式

化学反応式

$$\ce{CH4 + 2O2 -> CO2 + 2H2O}$$
$$\ce{C3H8 + 5O2 -> 3CO2 + 4H2O}$$
$$\ce{2Al + 6HCl -> 2AlCl3 + 3H2}$$

系数比 = 物质的量之比（气体则还 = 同温同压下体积比）。配平时先配复杂分子，再配 H、最后配 O；必要时用未定系数法。

过量与限量

過不足のある反応

方法　把各反应物的物质量除以系数，最小者为限量反应物，产物按它计算。

例题

例題

例题 1　丙烷燃烧

$\ce{C3H8}$ 22 g 完全燃烧，生成的 $\ce{H2O}$ 质量？

解答

$n=22/44=0.50\,\mathrm{mol}$，$\ce{H2O}$ 为 $4\times0.50=2.0\,\mathrm{mol}$，即 36 g。

练习题

練習問題（12 题，选择题；原子量 H 1.0, C 12, N 14, O 16, Na 23, Mg 24, Al 27, S 32, Cl 35.5, K 39, Ca 40, Fe 56, Cu 63.5, Ag 108，另有说明除外）

问 1原创 · EJU 风格

$\ce{CO2}$ 11 g 的物质量是？

  1. ① 0.25 mol
  2. ② 0.50 mol
  3. ③ 1.0 mol
  4. ④ 2.0 mol
解答

正解：①

$11/44=0.25$。

问 2原创 · EJU 风格

标准状况下 5.6 L 的 $\ce{O2}$ 中的分子数是？

  1. ① $1.5\times10^{23}$
  2. ② $3.0\times10^{23}$
  3. ③ $6.0\times10^{23}$
  4. ④ $1.2\times10^{24}$
解答

正解：①

$5.6/22.4=0.25\,\mathrm{mol}$，$\times6.0\times10^{23}$。

问 3原创 · EJU 风格

甲烷 8.0 g 完全燃烧所需 $\ce{O2}$ 在标准状况下的体积是？

  1. ① 11.2 L
  2. ② 22.4 L
  3. ③ 33.6 L
  4. ④ 44.8 L
解答

正解：②

$\ce{CH4}$ 0.50 mol，$\ce{O2}$ 1.0 mol → 22.4 L。

问 4原创 · EJU 风格

Al 5.4 g 与足量盐酸反应，生成的 $\ce{H2}$ 在标准状况下是？

  1. ① 2.24 L
  2. ② 4.48 L
  3. ③ 6.72 L
  4. ④ 8.96 L
解答

正解：③

$\ce{2Al + 6HCl -> 2AlCl3 + 3H2}$；Al 0.20 mol → $\ce{H2}$ 0.30 mol → 6.72 L。

问 5原创 · EJU 风格

$\ce{H2}$ 4.0 g 与 $\ce{O2}$ 16 g 混合点燃，生成的水的质量是？

  1. ① 9.0 g
  2. ② 18 g
  3. ③ 27 g
  4. ④ 36 g
解答

正解：②

$\ce{H2}$ 2.0 mol、$\ce{O2}$ 0.50 mol；$\ce{O2}$ 限量 → $\ce{H2O}$ 1.0 mol = 18 g。

问 6原创 · EJU 风格

某气体 1.4 g 在标准状况下占 1.12 L，其分子量是？

  1. ① 14
  2. ② 28
  3. ③ 32
  4. ④ 44
解答

正解：②

$1.12/22.4=0.050$ mol，$1.4/0.05=28$。

问 7原创 · EJU 风格

$\ce{CaCO3}$ 10 g 完全热分解（$\ce{CaCO3 -> CaO + CO2}$），剩余固体的质量是？

  1. ① 4.4 g
  2. ② 5.6 g
  3. ③ 6.0 g
  4. ④ 10 g
解答

正解：②

0.10 mol CaO = 5.6 g。

问 8原创 · EJU 风格

丙烷燃烧方程式 $a\ce{C3H8} + b\ce{O2 -> }c\ce{CO2} + d\ce{H2O}$ 中 $b$ 为？

  1. ① 3
  2. ② 4
  3. ③ 5
  4. ④ 7
解答

正解：③

$\ce{C3H8 + 5O2 -> 3CO2 + 4H2O}$。

问 9原创 · 过去问高频题型

$\ce{CuSO4.xH2O}$ $2.50\,\mathrm g$ 加热失去全部结晶水后剩 $1.60\,\mathrm g$。$x$ 是？（$\ce{CuSO4}=160$，$\ce{H2O}=18$）

  1. ① 3
  2. ② 4
  3. ③ 5
  4. ④ 6
解答

正解：③

$\ce{CuSO4}$ 0.0100 mol，水 $0.90/18=0.050$ mol，$x=5$。

问 10原创 · 过去问高频题型

$\ce{2NaHCO3 -> Na2CO3 + H2O + CO2}$。$8.4\,\mathrm g$ 碳酸氢钠完全分解，生成的 $\ce{CO2}$ 在标准状态下的体积是？

  1. ① $0.56\,\mathrm L$
  2. ② $1.12\,\mathrm L$
  3. ③ $2.24\,\mathrm L$
  4. ④ $4.48\,\mathrm L$
解答

正解：②

$8.4/84=0.10$ mol → $\ce{CO2}$ 0.050 mol → $1.12\,\mathrm L$。

问 11原创 · 过去问高频题型

$\ce{N2 + 3H2 -> 2NH3}$。$\ce{N2}$ 2.0 mol 与 $\ce{H2}$ 3.0 mol 完全反应，最多生成 $\ce{NH3}$ 多少 mol？

  1. ① 1.0
  2. ② 2.0
  3. ③ 3.0
  4. ④ 4.0
解答

正解：②

$\ce{H2}$ 限量：$3.0\times\frac23=2.0$ mol。

问 12原创 · 过去问高频题型

$\ce{CH4}$ 与 $\ce{H2}$ 等物质的量的混合气体 $100\,\mathrm{mL}$ 完全燃烧，所需同温同压的 $\ce{O2}$ 体积是？

  1. ① $100\,\mathrm{mL}$
  2. ② $125\,\mathrm{mL}$
  3. ③ $150\,\mathrm{mL}$
  4. ④ $200\,\mathrm{mL}$
解答

正解：②

$\ce{CH4 + 2O2 -> CO2 + 2H2O}$，$\ce{2H2 + O2 -> 2H2O}$：$50\times2+50\times\frac12=125\,\mathrm{mL}$。
